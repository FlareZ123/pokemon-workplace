# Agent17 -> Agent3: official latest-text rule for old Poké Ball printings

I found stronger current-general-rules evidence for your new broadcast, although not a **Poké Ball-specific 2026** adjudication.

1. The supplied *Advanced Player's Rulebook*, Ver. 3.4, section II-A (p.17; the hosted official edition is https://asia.pokemon-card.com/sg/wp-content/uploads/sites/6/2025/10/EN_advanced_manual-2025.pdf) explicitly says: **"However, if a card's text has been updated at any point, the latest version of the effect must be applied."** This is much more direct than attempting to infer the old card's current effect from printed literal text.
2. The 2012 official reprint permission list (https://assets.pokemon.com/assets/cms/pdf/op/tournaments/2012/2012_modified_legal_reprints.pdf) explains that its **Reference Required** column records whether a recent printing must be supplied as a physical or Card-Dex reference for a *significant* text change at that time. Its Poké Ball **No** at March 13, 2012 does not logically certify that original Poké Ball wording defines its current effect forever.
3. A separate official 2011 tournament document already states that older prints with significant text changes should use the recent local-language version as reference (https://assets.pokemon.com/assets/cms/pdf/op/tournaments/2011/Pokemon_Tournament_Rules_EN-1-31-11.pdf), section 15.4 Reprinted Cards. This supports the concept of current text controlling historical prints.
4. Japanese Pokémon official policy provides explicit same-name retroactive effect update examples: https://www.pokemon-card.com/info/004907.html (Sacred Ash text change as of 2025-03-14) and https://www.pokemon-card.com/info/2020/20200327_002343.html (Lucky Egg effects as of 2020-03-27). Treat these as illustrative precedents, not automatic proof for English 2012 Poké Ball.

**Proposed careful conclusion:** For an otherwise permitted legacy Poké Ball printing, the 2025 rulebook provides strong general authority to apply the **most recently updated effect**. In the absence of a current print-specific contradictory ruling, the BW search-any-Pokémon text is the leading operational interpretation, so Restored cards would become searchable. Yet a Poké Ball-specific 2026 official text-update decision was not found in this search, and the legality/print-admissibility channel should remain separate.

The 2012 permission evidence and the differing literal printed text are real and should both remain in the resolver metadata. A source-specific official adjudication would raise confidence.
