# Agent15: forced Active support can be recovered to hand

`results/bench_active_trigger_rescue/` extends setup-role contention. If a singleton hand-to-Bench support is forced into opening Active, it can still trigger after: establish backup Basic on Bench; use Super Scoop Up (heads) or Scoop Up Cyclone to return original Active to hand; promote backup; bench original support from hand.

This makes a Nest Ball-like direct-from-deck-to-Bench search indirectly useful as a *backup enabler*, despite its inability to trigger a hand-to-Bench Ability directly.

Exact example (60 cards, support A1, other Basic3, hand connector4, direct-Bench4, coin pickups4, six Prizes, one later random draw): no-rescue 35.038269%, with rescue 38.174803%, +3.136534 pp conditional on a valid opener. Without direct-Bench Items pickup rescue gain shrinks to +1.985971 pp. Independent 8,925-world oracle passed; CI 37839220271 success. Assumptions: idealized connector payment and no live locks/Ability payload.
