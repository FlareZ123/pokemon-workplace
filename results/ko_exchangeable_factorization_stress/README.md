# 20-effect stress test: 1,024 KO instance routes collapse to 11 conserved states

## Question

How much computation can be avoided by combining the two independently proven reductions in the KO result pipeline?

1. Factor exact effect-order analysis into independent destination-conflict components.
2. Quotient physical-instance destination vectors by final exchangeable card-class zone counts before running the full KO disposal kernel.

This experiment exercises both in one reproducible physical board.

## Construction

The initial materialized board has an Active Lapras with **10 Basic Water Energy cards** attached and a surviving Benched Bidoof. Both cards are represented by stable physical IDs. The initial ledger contains one Lapras, one Bidoof and 10 Basic Water Energy cards, all accounted for by materialization and attachment.

The active Lapras is then supplied as pending Knocked Out. For each Water Energy instance `water-i`, two abstract competing destination effects are specified: `keep-i` sends it to hand and `lose-i` sends it to Lost Zone. Whichever effect assigns the destination first wins. Each pair is independent of every other pair, and the omitted Lapras card itself defaults to discard.

These 20 synthetic destination programs are **not asserted to be produced by actual simultaneously triggered printed cards**. The board and movement operation are valid inputs to the repository's already existing physical conservation model; the effect programs create a controlled scalability stress test.

## Exact counts

There are 10 independent two-effect conflict components, and every Water instance can end up in one of two zones.

- `2^10 = 1,024` distinct instance-level destination vectors.
- `20!` labeled total effect orders.
- Every vector is generated by exactly `20! / 2^10` orders.

After the KO, each Basic Water copy is no longer attached to any Pokémon. Copies from the same gameplay-equivalence class therefore become exchangeable in the existing `IdentityLedger`. Final state depends only on the number `k` returned to hand, with the remaining `10-k` entering the Lost Zone.

There are exactly **11 conserved end states** (`k = 0,...,10`). For each `k`, the number of instance-specific routes that project to that state is `C(10,k)`. Its exact total effect-order multiplicity is

\[
M_k=\binom{10}{k}\frac{20!}{2^{10}}.
\]

The stress harness checks this formula separately for every conserved endpoint, along with the exact sum of route and effect-order multiplicities.

## Computational result

The baseline full-physical-projection strategy would need to dispose the Knocked Out board once per distinct instance destination vector, **1,024 disposals**.

The combined factorized and signature-grouped implementation instead executes the full physical cleanup **11 times**, once for each distinct exchangeable terminal state.

That is **1,013 avoided full physical disposal executions**, or **98.92578125% fewer** on this specific synthetic instance. No game-state information needed by the currently modeled destination-only problem is lost. The 1,024 instance route witnesses and their exact aggregate multiplicities are retained.

This is a reduction in calls to the physical cleanup kernel, not a benchmark of real-world CPU time, and does not represent tournament win probabilities.

## Reproduce

Run `python results/ko_exchangeable_factorization_stress/reproduce.py`. It constructs the board through the same materialization, attachment, KO preparation, promotion, and card-conservation layers used in previous agent6 results. It verifies the 10 conflict components, all exact instance-level order counts, the 11 terminal states, the binomial count of instance routes per terminal state, every conserved initial card-class total and the precise number of full disposal calls.

The companion GitHub Actions workflow is `.github/workflows/validate-ko-exchangeable-factorization-stress.yml`.

## Limitations

Exchangeable grouping requires the original card-class equivalence definition to be appropriate and all relevant per-copy identity/history to have ceased affecting future game actions. Effects that mutate surviving attachments, condition subsequent triggers, reveal hidden information, or grant prize/draw actions would need stronger state distinctions.

The source-authority solver is intentionally not invoked for this synthetic 20-effect fixture. The results are exact conditioned on the supplied destination programs, without implying these effect choices coexist under printed rules.
