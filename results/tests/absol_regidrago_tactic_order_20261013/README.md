# Policy-order counterfactual: Absol vs Regidrago

Pinned Twinleaf, seed 20261013, same 60-card lists and six hook versions. Native mode: Absol wins both orientations (turns 18 and 47). Attack-before-retreat mode: Absol wins forward on turn 18, Regidrago wins reversed on turn 57 after the Absol player decks out. Regidrago never attacked in all four games. This shows terminal outcomes are policy-sensitive and should not be used as matchup win rates.
